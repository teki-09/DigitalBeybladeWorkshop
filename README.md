# DigitalBeybladeWorkshop
I made a Beyblade webpage for fun, with a dashboard, a searchable parts catalogue and a combo builder. The arena in my Beyblade webpage uses Canvas drawings, an animation loop and a small set of movement and collision rules. Skill tree, practice interface and localized JSON backups

| Feature / Module | Implementation Details |
| --- | --- |
| **Dashboard** | Counts, win rate, finish counts in wins, and recent records are derived from stored records. |
| **Builder** | Component selection, attribute totals, colour changes, drawing, and save action are implemented. |
| **Comparison** | Raw attribute differences and a simple attack or stamina verdict update. |
| **Experiment and Heatmap** | Their interfaces are present. |
| **Explorer** | All 18 parts can be browsed and filtered by category or name. |
| **Visualiser** | A rotating procedural 2D Canvas drawing. |
| **Arena** | Launch vectors, centre pull, damping, overlap response, rail boost, and spin/burst endings are implemented. |
| **Match Log** | Manual outcomes, victory only point totals, W/L/D, and exportable records. |
| **Training** | XP can be spent and cards can unlock during a session. |
| **Practice** | Form fields and example rows exist. |
| **Persistence** | Combinations and match logs save to localStorage; state can be exported as JSON. |
| **Offline Use** | Application logic and records are local. |
